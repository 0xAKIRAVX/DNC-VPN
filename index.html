Why DNC VPN

Everything a VPN should be

Every feature exists to solve one problem: a stable connection on Iranian networks.

Tuned for Iranian networks

Built against Irancell, MCI, Rightel and ADSL. The gold tier is ranked by real-traffic tests, so the top of your list is already the best of the crop.

A hand-picked speed tier

The Selected group holds 20 configs we ran through real tunnels — connectivity, download and upload measured, then ranked. Re-tested every 3 hours: dead ones never survive.

Servers that never go stale

A GitHub Actions job rebuilds the subscription every five minutes. Open the app, tap Update, and last night's dead configs are gone.

Every modern protocol

VLESS + Reality, VMess over CDN, Trojan, Shadowsocks, Hysteria2 and TUIC — pick whatever your network lets through today.

Fragment, for stubborn networks

A built-in TLS-fragmentation switch, made with Irancell in mind. Test it on and off — it takes ten seconds and often saves the day.

Per-app routing

Choose exactly which apps travel through the tunnel and which stay on your ordinary connection.

Free, with no strings

No account, no fees, no trial timer. Nothing is sent to a server we run — your config list is fetched straight from GitHub.

Modes

Which config should I pick?

A quick guide. Start at the top and work your way down until one flies.

ProtocolBest forNotes
VLESS + Reality · 443 First choice on every operator Looks like ordinary TLS — the best chance against DPI.
VMess / ws + TLS over CDN When direct server IPs are blocked Rides a CDN; ports 443, 2053, 2083, 2087, 2096.
Trojan A light, stable fallback Prefers port 443.
Shadowsocks Speed on good days Can get detected at busy hours; swap it out if ping works but pages don't.
Hysteria2 / TUIC · UDP Only if your network allows UDP Most Iranian networks throttle UDP heavily.
Fragment Irancell, when all else fails Toggle it in Settings and test both states.

Remember: the in-app ping test measures TCP only. A config that pings but won't load pages is a dead config — switch to the next one.

Get connected

Up and running in three steps

From download to a working tunnel in under two minutes.

STEP 01

Download

Grab the APK from GitHub Releases — or the Picofile mirror if GitHub is being difficult. The file is about 62 MB.

STEP 02

Install

Android 7+, arm64-v8a. It installs right over any older DNC build; if Android refuses, remove the old app once and retry.

STEP 03

Connect

Open the Free group, tap Update, run ⋮ → Test all, sort by ping — and connect to the config at the top.
